# Iris Flower Classification

## Objective
To classify Iris flowers into three species using machine learning.

## Dataset
The built-in Iris dataset from Scikit-learn, containing 150 samples and 4 measurement features.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Steps Performed
1. Loaded and explored the dataset.
2. Visualized flower measurements.
3. Split data into training and testing sets.
4. Trained Logistic Regression and Random Forest models.
5. Compared model accuracy.
6. Evaluated the best model using a confusion matrix and classification report.

## Results
Two machine learning models were compared, and the model with the higher test accuracy was selected.

## Conclusion
The project demonstrates how machine learning can classify Iris flower species from their measurements.

## How to Run
Open the notebook in Google Colab and run the cells in order.
