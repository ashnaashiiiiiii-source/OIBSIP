# Unemployment Analysis with Python

## Objective
To analyze unemployment trends in India using Python and visualize changes across different regions and time periods.

## Dataset
Unemployment in India dataset containing regional unemployment rates, estimated employment, labour participation rates, and dates.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data cleaning and preprocessing
- Region-wise average unemployment analysis
- Monthly unemployment trends
- Comparison of selected regions
- Top 10 regions by unemployment rate
- Correlation heatmap
- Pre-COVID and COVID-period comparison

## Conclusion
The analysis explores differences in unemployment rates across regions and changes over time. The visualizations help identify regional patterns and changes during the COVID-19 period.
