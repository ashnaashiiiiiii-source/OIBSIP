# Car Price Prediction with Python

## Objective
To build a machine learning model that predicts car prices based on different vehicle features.

## Dataset
Car Price Prediction dataset from Kaggle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Steps Performed
1. Loaded and inspected the dataset.
2. Cleaned missing and duplicate values.
3. Converted categorical variables into numerical values using one-hot encoding.
4. Selected input features and the target variable.
5. Split the dataset into training and testing sets.
6. Trained a Linear Regression model.
7. Predicted car prices using the trained model.
8. Evaluated the model using Mean Absolute Error (MAE) and R² Score.
9. Visualized actual prices against predicted prices.

## Machine Learning Algorithm
**Linear Regression** was used to predict car prices based on the available vehicle features.

## Evaluation Metrics
- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted prices.
- **R² Score:** Measures how well the model explains variations in car prices.

## Conclusion
This project demonstrates how machine learning can be used to predict car prices. The model's performance is evaluated using MAE and R² Score, and a graph compares actual prices with predicted prices.
